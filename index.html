cremalink-ha

A Home Assistant integration for monitoring and controlling De’Longhi coffee machines — powered by cremalink.

✨ Overview

The integration connects to a De’Longhi coffee machine over local LAN (preferred — low latency, no cloud dependency) or the De’Longhi cloud API, exposing the machine’s live state, profiles, settings, statistics, and brew actions as Home Assistant entities.

Entities include:

  • Sensors — machine status, statistics counters

  • Selects — profile selection and writable machine settings (auto-off, water hardness)

  • Switches — power, beep, energy saving (machine-confirmed writes)

  • Buttons — brew beverages and machine actions

  • Binary sensors — accessory/alert states

Local mode runs an embedded cremalink LAN server in-process: session keep-alives, command queuing, and datapoint republish handling are managed for you.

🚀 Installation

Via HACS as a custom repository:

  1. HACS → ⋯ → Custom repositories → add https://github.com/lodzen/cremalink-ha (category: Integration)

  2. Install Cremalink for Home-Assistant

  3. Restart Home Assistant

  4. Settings → Devices & Services → Add Integration → Cremalink

The config flow discovers machines on the LAN (or accepts your cloud credentials for cloud mode).

🛠 Development

Testing

pytest tests/

The test suite stubs homeassistant modules — no full HA install is needed to run it.
