async async_press()[source]

Handle the button press.

property available

Stop only while a brew runs; drinks unless asleep, waking or brewing.

The transition into standby (going_to_sleep) does not make any button unavailable; standby itself does. A press during the transition is rejected in async_press(). is_busy (the monitor’s action byte, latched in standby) only counts as a running brew while the status says so.
