cremalink_ha.diagnostics module

Diagnostics support for Cremalink.

Redacts the sensitive fields introduced by cloud-assisted onboarding (spec FR-013): cloud account email/password, access/refresh tokens, and the LAN key. Modeled directly on delonghi_coffee’s diagnostics.py.

cremalink_ha.diagnostics.USER_NAME_BLOB_FAMILIES = {b'\xa4\xf0', b'\xaa\xf0', b'\xba\xf0'}

Blob families carrying user-entered names (profile names a4f0, recipe names aaf0, bean-system baf0). Their contents are elided from diagnostics; the frame header + slot indices stay.
