cremalink_ha.number module

Number platform — per-recipe parameter sliders (spec FR-008..010).

One entity per user-adjustable recipe parameter (cremalink.ecam.params .PARAMS). Bounds, labels, units, and steps come from the machine’s 0xB0 descriptor; the shown value is the pending override if set, else the loaded profile-stored value — machine defaults only when the read fell back (values_source attribute).

Setting a value only records a raw override in the recipe session — nothing is written to the machine until button.brew_recipe merges the overrides into one 0x83 brew frame (transient; spec Q2).
