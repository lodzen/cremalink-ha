cremalink_ha.const module

Constants for the Cremalink Home Assistant integration.

cremalink_ha.const.BUTTON_UNAVAILABLE_STATUSES = {'deep_sleep', 'in_standby', 'sleeping', 'waking_up'}

asleep or waking up. going_to_sleep is deliberately absent — the transition into standby must not grey the buttons out, only reaching standby does.

Type:

Statuses in which the drink buttons are unavailable

cremalink_ha.const.NOT_BREWING_STATUSES = {'deep_sleep', 'going_to_sleep', 'in_standby', 'rinsing', 'sleeping', 'waking_up'}

Statuses in which the monitor’s action byte does not mean “a drink is being brewed”: the standby family (the byte stays latched), waking up, and the power-on/off rinse. Button availability must not follow it there.

cremalink_ha.const.NOT_READY_STATUSES = {'deep_sleep', 'going_to_sleep', 'in_standby', 'sleeping', 'waking_up'}

Statuses in which the machine cannot start a drink (asleep or still waking).

cremalink_ha.const.STANDBY_STATUSES = {'deep_sleep', 'going_to_sleep', 'in_standby', 'sleeping'}

Statuses during which the machine stops evaluating alarm/switch/accessory bytes — latched values must not surface as live readings (T044/FR-034).

cremalink_ha.const.TRANSLATED_COMMANDS = frozenset({'americano', 'caffe_latte', 'cappuccino', 'cappuccino_mix', 'cappuccino_plus', 'coffee', 'cortado', 'doppio_plus', 'double_espresso', 'espresso', 'espresso_macchiato', 'espresso_soul', 'flat_white', 'hot_milk', 'hot_water', 'latte_macchiato', 'long_coffee', 'stop'})

Device-map commands that have an entity translation (cmd_<command>). Commands of custom maps fall back to a generated English name.
