cremalink_ha.switch module

Switch platform for the Cremalink integration.

  • Power — the device’s on/standby control (no entity category).

  • Param-63 bit settings (beep, energy saving, …) — configuration switches backed by a session-gated 0x90 write that merges the flag into the shared user-config word (Device.set_setting_bit).

class cremalink_ha.switch.CremalinkSettingSwitch(*args: Any, **kwargs: Any)[source]

Bases: CoordinatorEntity[CremalinkCoordinator], SwitchEntity

A boolean flag inside the shared param-63 user-config word.

Writes go through Device.set_setting_bit: the current word is read first and the flag merged in, so unrelated bits survive (protocol.md §14.8). State only ever reflects machine-confirmed values.
